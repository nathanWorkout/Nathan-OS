#+title: VaultFS - Three State Filesystem

* YES vaultfs_init
- memset tout à zéro (layers, profils, nodes)

* YES vaultfs_resolve
- Chercher dans C2 du profil :
  - Si trouvé et type == VAULT_DELETED -> retourner NULL (fichier masqué)
  - Si trouvé -> retourner node C2
- Chercher dans C1 :
  - Si trouvé -> retourner node C1
- Chercher dans C0 :
  - Si trouvé -> retourner node C0
- Retourner NULL

* YES vaultfs_create
- Trouver le profil via profile_id
- Vérifier count < 128, sinon retourner NULL
- Remplir prochain node libre dans layer2 du profil :
  - Copier nom/chemin (max 127 chars + '\0')
  - Mettre le type (VAULT_FILE, VAULT_DIR, VAULT_DELETED)
  - data = NULL, size = 0
  - owner_profile_id = 0
- Incrémenter count
- Retourner pointeur vers node C2

* YES vaultfs_write
- target_node = vaultfs_resolve(fs, profile_id, path)
- Calculer in_c0 / in_c1 seulement si target_node != NULL
- Si target_node != NULL et type == VAULT_DIR -> retourner erreur
- Si in_c0 -> retourner erreur (C0 immuable, même en copie)
- Si target_node == NULL :
  - target_node = vaultfs_create(fs, profile_id, path, VAULT_FILE)
- Sinon si in_c1 :
  - target_node = vaultfs_create(fs, profile_id, path, target_node->type) (copy-on-write en C2)
- Sinon (déjà en C2) :
  - Si target_node->data != NULL -> pmm_free_page(target_node->data)
- Si size > PAGE_SIZE -> retourner erreur (limitation V0.1)
- phys = pmm_alloc_page()
- Copier data dans phys_to_virt(phys)
- target_node->data = phys
- target_node->size = size
- Retourner succès
